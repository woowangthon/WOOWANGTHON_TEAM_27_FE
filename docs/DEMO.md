# 시연 시나리오 (영상·발표용)

MVP 계획의 5단계 스토리를 앱에서 이렇게 보여줍니다. 핵심 장면은 `샘플` 배지가 붙은 데모 데이터(`lib/data/sample_data.dart`)를 사용하므로, 실제 공공데이터가 바뀌어도 시나리오가 깨지지 않습니다. 나머지 화면(발견, 마감 공고, 교통 통제)은 실제 데이터입니다.

## 시연 영상 규칙 (대회 규정)

- 5분 이내, YouTube 공개 또는 일부 공개
- 앞뒤 불필요한 구간만 컷 편집 — **실행 생략·결과 조작 금지**
- 배속 가능 (영상 우측 상단에 표시)
- **일반 설명 자막 금지** — 배속·샘플·모킹 표시는 가능
- 샘플 데이터 장면에서는 화면의 `샘플` 배지가 보이도록 촬영합니다

## 날짜

| 항목 | 날짜 (11/14까지 기준) |
|---|---|
| 부산 출장 (일정) | 11/20 ~ 11/22, 해운대 |
| 부산 대형 콘서트 | 11/20, 아시아드 주경기장 |
| 대전 AI 세미나 | 11/20, **신청 마감 11/15** |
| AI & 스타트업 엑스포 (벡스코) | 11/21, 마감 11/18 |

11/15부터는 모든 샘플이 **주 단위로 앞당겨집니다.** 부산 출장은 항상 오늘로부터 6~12일 뒤에 위치하므로, 심사위원이 나중에 앱을 열어도 시나리오 카드가 나타납니다. 요일과 간격은 유지됩니다.

## 준비

- [ ] `env.json`에 `GEMINI_API_KEY` 설정 (없으면 카드 문장은 규칙 기반 문장으로 표시)
- [ ] 촬영 전에 앱을 한 번 열어 둡니다 — Gemini 문장이 기기에 캐시되어 바로 표시됩니다
- [ ] 프로필 → 알림 켜기 (5단계)
- [ ] Google 캘린더는 연결하지 않은 상태 (샘플 일정 표시). 연결했다면 실제 캘린더에 "부산" 일정이 있어야 합니다
- [ ] 휴대폰에서 카카오 지도·Google 로그인 동작 확인

## 단계

1. **로그인과 관심사** — Google 로그인(또는 게스트) → 관심사 **AI, 스타트업, 음악·공연**.
2. **홈 → 신호 카드** — 첫 카드: 부산 출장 날 근처에서 대형 행사.
   - 카드 아래 **일정 연결 줄**: "11월 20일 · Busan trip / 같은 날 · 2.4 km 거리" — 왜 이 신호가 떴는지 한눈에 보입니다.
   - 공식 교통 영향 정보가 없으므로 "확인되지 않음"으로 표시하고 알림은 보내지 않습니다 (행사 개최만으로 교통 영향을 단정하지 않음).
   - 카드를 열면 ✨ AI가 쓴 이유, 신뢰도, 출처.
3. **지도 → 경로** — 서울역 → 부산역, 출장 첫날(11/20), 대중교통 → 경로 근처의 **대전 AI 세미나 +7.1 km · +17분**. 자동차로 바꾸면 고속도로가 대전에서 멀어 추천되지 않습니다 → *이동 수단까지 고려하는 추천*.
4. **행사 → 행동** — "캘린더에 추가" → 세미나가 일정이 되고 홈이 추적을 시작합니다. 결정은 사용자가 합니다.
   - 샘플 행사에는 신청 링크가 없습니다. "신청하기" 버튼은 발견 탭의 **실제** 행사(TourAPI·K-Startup 공식 링크)로 보여줍니다.
5. **알림** — 세미나 신청 마감이 2일 이내가 되면(11/13부터) 앱을 열 때 시스템 알림: *"신청 마감이 다가와요"*. 현재는 기기 내 알림이며, 서버 푸시(FCM) 설계는 [PUSH_NOTIFICATIONS.md](PUSH_NOTIFICATIONS.md).

**추가 장면**
- **뉴스로 본 파업 (실제 데이터)** — 부산 출장(11/20) 카드 옆에 *"전국철도지하철노조 파업 예고 (11월 20일)"* 참고 카드. 열면 기사 원문 인용과 링크, "공식 공지가 아니므로 참고용". AI가 해외 시위·드라마·끝난 파업은 걸러냈다는 점을 설명 (데이터는 3시간마다 갱신되므로 촬영 시점의 실제 보도로 바뀔 수 있음 — 결과를 고정하지 않음).
- **피드백** — 콘서트 카드에 👎 두 번 → 비슷한 콘서트가 내려가고 AI 행사가 올라옵니다.
- **공식 교통 통제** — 서울 TOPIS(시내) 또는 ITS(전국 고속도로·국도)에 통제가 있는 장소 근처에 일정을 만들면 "인근 통제" 카드가 출처·통제 시간과 함께 나타납니다 (통제가 있을 때만 — 결과를 고정하지 않음).
