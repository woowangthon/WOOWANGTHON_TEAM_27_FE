# 이동 경로별 교통 영향 알림 재검증

## 확인한 범위

- 저장한 이동 경로와 파업·통제의 시간, 교통수단, 노선/시설 일치 여부.
- 알림 중복 방지, 파업 철회, 발송 실패 후 재시도.
- 현재 운영 중인 데이터 공급원과 실제 경로 조회.
- Android 알림 설정 및 실제 알림 등록 여부(기기 검증 항목 참조).

## 자동 테스트

`test/news_traffic_test.dart`, `test/travel_impact_test.dart`, `test/traffic_v2_test.dart`: 26개 통과.

이 테스트의 알림 발송기는 대체 구현이다. 따라서 이것만으로 휴대폰의 실제 알림 수신까지 검증됐다고 보지 않는다.

## 실제 데이터 조회

[실제 데이터 조회 결과](traffic-live-20261113.json)에 사용자 캘린더를 변경하지 않은 시험 경로 4개의 조회 결과를 저장했다.

- 서울역→봉은교: 실제 경로 조회, 현재 정체 및 공사 통제 알림 대상 판정.
- 서울역→부산역: 실제 대중교통 경로 조회, 해당 시험 시간대의 알림 대상 없음.
- 서울역→덕수궁: 현재 정체 알림 대상. 주변 마라톤 일반 정보는 알림 대상에서 제외.
- 신촌→연세대: 공식 대중교통 우회·이용 제한 공지가 매칭되어 알림 대상 판정.

일부 조회에서 TOPIS 공식 실시간 공지 또는 ITS가 실패했다. 실패한 조회는 정상 운행이라는 근거로 사용하지 않았다. 이 결과는 조회 시점의 상태이며, 모든 공급원이 항상 정상이라는 보장이 아니다.

## 기기 검증

연결된 테스트 기기에서 최초 점검:

- 앱 내부 알림 설정: 켜짐.
- Android 앱 알림 권한: 허용.
- `signals` 알림 채널 중요도: 4(높음).

진단 전용 진입점 `tool/verify_traffic_notifications_device.dart`는 운영 코드의 저장 경로 모델, 영향 판정기, 알림 발송기와 실제 Android 알림 플러그인을 연결한다. 사용자 설정·계정·일정은 메모리 저장소로 격리해 변경하지 않는다. 2026-11-10의 고정 시험 데이터를 재생하며 휴대폰 시계는 변경하지 않는다. 알림 제목에는 `[검증용]`, 본문에는 실제 파업·통제가 아니라는 설명을 붙인다.

검증 시나리오: 경로가 일치하는 파업 발송, 동일 경고 중복 억제, 다른 노선 억제, 다른 시간 억제, 경로가 일치하는 행사 도로 통제 발송.

실기기 검증 완료. 결과는 [실기기 검증 결과](traffic-device-20261113.json)에 저장했다.

| 시나리오 | 결과 |
| --- | --- |
| 저장 경로와 일치하는 파업 | 실제 알림 발송 성공 |
| 동일 경고 재평가 | 중복 발송 없음 |
| 다른 노선의 파업 | 알림 없음 |
| 이동 시간과 겹치지 않는 영향 | 알림 없음 |
| 저장 경로와 일치하는 행사 도로 통제 | 실제 알림 발송 성공 |

앱 발송 결과의 `passed=true`, `sent=2`를 확인했다. 별도 Android instrumentation의 `NotificationManager.getActiveNotifications()`에서도 검증용 파업·행사 알림 2건을 확인했다. 알림 배너가 화면에 나타나는 모습까지 촬영한 검증은 아니다.

시험 후 검증 알림이 0건으로 정리된 것을 확인하고 임시 instrumentation APK를 제거했다. 원본 SHA-256이 `9d238a832821d5a4ef77890aa0d94301c56f4423fcb23078f8fc588efd255f52`인 기존 앱(v2016 / 1.0.1)을 데이터 삭제 없이 복원했으며, 원래 앱 실행 및 주간 공모전 수집 작업 등록도 확인했다.

## 현재 구현의 한계

교통 갱신은 앱 실행·복귀 및 실행 중 5분 주기에 연결돼 있다. 앱이 완전히 종료된 상태에서 새 파업·행사 정보를 자동 수집하고 교통 알림을 발송하는 백그라운드 작업은 없다. 기존 주간 공모전 수집 작업은 교통 알림을 처리하지 않는다.

근처 행사 정보나 짧은 파업 기사만으로 개인 경로에 교통 마비가 확정됐다고 알리지 않는다. 확인된 영향과 저장한 경로·시간 등의 일치 조건을 충족해야 한다. 따라서 공급원에 검증된 영향 정보가 없으면 관련 알림을 놓칠 가능성이 남는다.
